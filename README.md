# division-drop

Картинки предметов для раздела **ДропКлады** скрипта Division.

## Как добавить предмет
1. Залей картинку в папку `drop`.
2. Имя файла = `ID - Название предмета.png` (например `1808 - Смазка для разгона видеокарты.png`).
3. Добавь имя файла новой строкой в `drop/index.txt` (или удали index.txt — тогда список берётся автоматически через GitHub API).

Поддерживаются `.png`, `.jpg` и `.b64` (base64-текст картинки — используется, когда файл заливается через API).

Скрипт кэширует картинки в `moonloader\\Division\\resource\\drop`.
